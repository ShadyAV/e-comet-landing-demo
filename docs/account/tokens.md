# Юрлица и токены

Источник: https://shadyav.github.io/e-comet-landing-demo/docs/account/tokens/ · Обновлено: 20 ноября 2026

## Юрлица

Юрлицо - это кабинет продавца на Wildberries. Для его добавления нажмите на кнопку "+ Юрлицо", введите токен API Wildberries и нажмите "Сохранить". Затем укажите произвольное название и снова нажмите "Сохранить".

## Токен API

## Что такое токен API?
Токен позволяет e-Comet подключиться к вашему кабинету Wildberries и использовать нужные разделы: **аналитика**, **вопросы и отзывы**, **контент**, **продвижение**, **статистика**. 

> **Совет. Одобрено Wildberries.**
> Данный способ подключения официально одобрен и рекомендован Wildberries. 

## Как подключить токен API?

> **Важно. Используйте только сервисный токен e-Comet.**
> **Персональный** и **базовый** токены не поддерживаются и для подключения к e-Comet не подойдут.

1. Сформируйте ключ API в [личном кабинете продавца](https://seller.wildberries.ru/api-integrations) на Wildberries:
```
Профиль → Интеграции по API → Создать токен → Для сервиса из каталога → e-Comet
```

   ![Создание сервисного токена e-Comet в кабинете Wildberries](https://shadyav.github.io/e-comet-landing-demo/docs/img/wb-service-token-ecomet.webp)

2. В личном кабинете e-Comet:
   - нажмите 📝 напротив юрлица
   - вставьте токен в открывшееся окно
   - нажмите "Сохранить"

   ![Окно добавления токена API в e-Comet](https://shadyav.github.io/e-comet-landing-demo/docs/img/account-token-connect.webp)

> **Внимание. Создать токен может только владелец.**
> Генерация токена доступна только владельцу кабинета продавца на Wildberries.

> **Важно. Не блокируйте функционал.**
> Не выбирайте пункт "Только на чтение" и "Тестовый контур". Это приведет к невозможности вносить изменения и, как следствие, к неработоспособности функционала управления рекламой.

В e-Comet могут потребоваться следующие разделы, желательно добавить их все:

| Раздел e-Comet      | Нужные разрешения в токене                                                                                                       |
|---------------------|--------------------------------------------------------------------------------------------------------------------------------- |
| Реклама         | Аналитика, Продвижение, Статистика, Вопросы и отзывы (для триггеров по отзывам) |
| А/Б-тесты       | Аналитика, Контент, Продвижение                                             |
| Портфель        | Аналитика, Контент или Продвижение                                          |
| Лента           | Статистика                                                                  |
