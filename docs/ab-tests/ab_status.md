# Статусы А/Б-тестов

Источник: https://shadyav.github.io/e-comet-landing-demo/docs/ab-tests/ab_status/ · Обновлено: 23 апреля 2026

Запланирован - Тест создан и запустится автоматически в выбранные дату и время

Активен - Фотографии находятся в процессе тестирования

Остановлен - Вы самостоятельно остановили тест до его завершения

Завершён - Тест успешно проведён, можно изучить результаты

Ошибка - Во время теста произошла ошибка (например, товар закончился). Кликните на тег для деталей ошибки

В архиве - Тест был отправлен в архив

> **Заметка. Детали работы.**
> Значок молнии ⚡ отображается только у тестов, запущенных в экспресс методе.
