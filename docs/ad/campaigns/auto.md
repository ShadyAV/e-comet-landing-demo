# Что такое "Единая" рекламная кампания?

Источник: https://shadyav.github.io/e-comet-landing-demo/docs/ad/campaigns/auto/ · Обновлено: 25 сентября 2025

**"Единая" РК** - это полностью автоматическая реклама от Wildberries, где все зоны показов включены сразу, а ставка едина для всех зон. Нужно лишь выбрать, по какой зоне (Поиск или Полки) оптимизировать управление ставкой. Это не отключает остальные зоны, а только определяет фокус оптимизации.

> **Заметка. Главная особенность.**
> "Единая" РК продвигает товары **по одной ставке за 1000 показов (CPM) во всех зонах**.

> **Важно. Оплата за клик (CPC).**
> Рекламные кампании с моделью оплаты "за клик" (CPC) не поддерживаются API ВБ. Управлять ими можно только в кабинете продавца на ВБ.

## Где показывается "Единая" РК

1. **Поиск**
2. **Каталог**
3. **Рекомендательные полки**:
   - Главная страница и раздел "Подобрали для вас"
   - Под карточками других товаров
   - Разделы "Похожие товары", "Похожие по фото", "Поиск по фото", "Посмотрите, что мы нашли"
   - Сопутствующие товары после оформления заказа
   - Раздел "Клубные скидки", если на ваши товары установлена скидка WB Клуба

## Основные принципы работы

- Зоны показов Поиск и Полки включены автоматически (отключить нельзя)
- Ставка одна для всех зон
- Необходимо выбрать **одну зону показов** (Поиск или Полки), по которой будет осуществляться мониторинг позиции в выдаче и управление ставкой

### Зона показов Поиск
- Задаете целевые фразы
- Доступно управление кластерами
- Доступна статистика по кластерам

> **Внимание. Кластеры ≠ фразы.**
> В "Единой" РК используется логика работы с использованием кластеров, а не отдельных ключевых фраз. [Подробнее о кластерах](https://shadyav.github.io/e-comet-landing-demo/docs/ad/campaigns/preset/).

### Зона показов Полки
- Задаете целевые артикулы ВБ
- Нельзя включить / отключить конкретные полки 
- Статистика по полкам недоступна 

> **Совет. Формула успеха.**
> Эффективность продвижения зависит от множества параметров: конверсия карточки товара, ключевые слова в карточке, позиция в органической выдаче, география поставок, участие в акциях, рейтинг карточки по отзывам и другие.

> **Заметка. Если нет показов.**
> Если ВБ не показывает рекламную кампанию в выдаче по какой-то из фраз / полок, то повлиять на это со стороны биддера невозможно - см.
