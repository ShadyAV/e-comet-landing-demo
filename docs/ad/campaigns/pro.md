# Функционал PRO

Источник: https://shadyav.github.io/e-comet-landing-demo/docs/ad/campaigns/pro/ · Обновлено: 20 ноября 2026

Набор функций, доступный на тарифе "Проф", который содержит: 

- Продвинутую аналитику
- Более ресурсоемкие правила управления РК
- Средства автоматизации для больших кабинетов, экономящие время при большом количестве РК под управлением

На остальных тарифах доступна пробная версия PRO, действующая в течение пяти дней.

> **Совет. Больше с PRO.**
> На всех тарифах, кроме Базовый и Проф, доступно 3 целевые фразы.
> На тарифе Базовый - 10 целевых фраз.
> На тарифе Проф - 20 целевых фраз.

## Контроль расходов PRO

Функционал позволяет автоматизировать контроль рекламных расходов по товарам и юрлицам. Он является расширенной версией дневного лимита расходов, который можно задать в настройках конкретной РК в поле "Макс. расход".

Переключатель "Активен" контролирует работу функционала для всего аккаунта:

  - ![](https://shadyav.github.io/e-comet-landing-demo/docs/img/switch_on_pro.png) **Вкл**: Осуществляется контроль расходов согласно лимитам по юрлицам и артикулам
  - ![](https://shadyav.github.io/e-comet-landing-demo/docs/img/switch_off.png) **Выкл**: Контроль не осуществляется

> **Внимание. Контроль без границ.**
> Лимит расходов внутри РК работает независимо. Он продолжит работать, даже если контроль расходов PRO отключен.

> **Заметка. Детали работы.**
> Выделенные синим цветом колонки можно редактировать двойным кликом внутри ячейки таблицы.

### Лимит по юрлицам

Кнопка "Лимит юрлиц" позволяет указать дневной лимит расходов для каждого юрлица. В таблице доступен список ваших юрлиц, количество кампаний и статистика по расходам за 30 дней.

Если лимит будет превышен, то все РК юрлица будут поставлены на паузу до конца дня.

### Лимит по артикулам

В общей таблице вы можете установить дневной лимит для каждого товара. Если лимит будет превышен, то РК с данным артикулом встанут на паузу до конца дня.

Таблица поддерживает все стандартные функции в сервисе, такие как сортировка, фильтрация и настройка. Подробнее ознакомиться с таблицами можно в статье ["Инструменты: Таблицы"](https://shadyav.github.io/e-comet-landing-demo/docs/tools/sheets/).

> **Заметка. Детали работы.**
> Отображаются только юрлица с активным токеном API и категорией "Продвижение".

> **Совет. Где искать.**
> Раздел "Реклама" → кнопка ![Контроль расходов PRO](https://shadyav.github.io/e-comet-landing-demo/docs/img/pro_control.png)

## Артикул PRO
Таблица с дневной динамикой всех основных показателей эффективности рекламы. Представляет собой воронку конверсий от рекламных показов до выкупов и доли рекламных расходов.

![Таблица «Артикул PRO» с раскрытыми группами метрик для одного артикула](https://shadyav.github.io/e-comet-landing-demo/docs/img/pro_product1.webp)

**Объединяет данные из нескольких источников:**

- Отчет "Воронка продаж" из "Аналитики продавца" на Wildberries
- Статистика по рекламным кампаниям под управлением

**Список метрик (для большинства метрик - с разбивкой на органику / рекламу):**
- Расходы
- Показы
- Тип трафика
- Ставка за тыс. показов (CPM)
- Конверсия в клик (CTR)
- Клики
- Стоимость клика (CPC)
- Конверсия в корзину (CR1)
- Корзины
- Стоимость корзины (CPB)
- Конверсия в заказ (CR2)
- Заказы
- Стоимость заказа (CPO)
- Цена после СПП
- СПП (скидка постоянного покупателя)
- Цена до СПП
- Выручка до СПП
- ДРР (доля рекламных расходов)
- Процент выкупа
- ДРР по выкупам (TACoS)
- Выкупили товаров
- Выкупили на сумму 
- Возврат на инвестиции в маркетинг (ROMI)
- Остатки (всего)
- Остатки на МП (складе продавца)
- Остатки на складах WB 

> **Заметка. Разбивка по зонам показов.**
> Нажмите "Развернуть все", чтобы увидеть метрики по зонам показов. Нажмите "Свернуть все", чтобы получить компактный вид. Система запомнит ваш выбор и применит его при следующем открытии таблицы.

**Количество РК:** в тултипе 2 РК указано количество рекламных кампаний артикула. Цвет меняется в зависимости от количества: 

- 1 РК - 1 рекламная кампания
- 2 РК - 2 рекламные кампании
- 3 РК - 3 и более рекламных кампаний

**Переключатель «Склейка» (1):** при активации в таблице отображаются данные по всем артикулам в склейке (объединение карточек товаров). Это позволяет учитывать влияние рекламы на общие результаты, включая артикулы, не участвующие в рекламных кампаниях. При выключенном состоянии данные отображаются только по отдельным артикулам.

![Переключатель «Склейка» включён над таблицей «Артикул PRO»](https://shadyav.github.io/e-comet-landing-demo/docs/img/sku_merge1.webp)

> **Заметка. Формула общего ДРР склейки.**
> ДРР склейки = расходы за период / выручка за период всех артикулов в склейке.

> **Совет. Продвинутый анализ в Артикул PRO.**
> - Можно выбирать и агрегировать данные не только по одному артикулу или склейке, а по **нескольким артикулам сразу** (и их склейкам!)
> - Можно задать **тег** набору артикулов и выбирать этот набор в **один клик** - удобно для анализа групп товаров

> **Внимание. Взгляд из-под капота.**
> - Расходы учитываются только у РК, которые под управлением e-Comet
> - Выручка учитывается не только по артикулам, участвующим в РК, но и по тем, у которых была выручка без рекламы. Эти данные берутся из отчета "Воронка продаж", что позволяет корректно учитывать рентабельность рекламы и избежать завышения ДРР

**Количество артикулов:** в плашке 3 указано количество артикулов в склейке. По нажатию на плашку (2) при включённом переключателе «Склейка» открывается окно, где видны:

- Номера артикулов, входящих в склейку
- Фотографии товаров

Это помогает быстро идентифицировать все товары, участвующие в склейке.

![Состав склейки с фотографиями и номерами трёх артикулов](https://shadyav.github.io/e-comet-landing-demo/docs/img/sku_merge_tt1.webp)

**Переключатель "Воронка":** позволяет выбирать между двумя режимами расчетов:

1. Стандартный метод - данные о конверсии в корзину и в заказ берутся из статистики по рекламе с Wildberries без обработки

2. Альтернативный метод ("Воронка") - делаются допущения, что:

- Конверсия в корзину одинакова для органического и рекламного трафика 
- Статистика по общей статистике артикула (независимо от вида трафика) более точная 

Таким образом, конверсия в корзину (CR1) и конверсия в заказ (CR2) берутся из отчета "Воронка продаж". 

Использование данного подхода позволяет получить более реалистичные метрики: корзины, заказы, ДРР и стоимость заказа (CPO), так как качество данных в статистике рекламы от маркетплейса по конверсиям в корзину и в заказ вызывает вопросы.

> **Совет. Где искать.**
> Реклама → Статистика → Артикул PRO.
