Сертифицированное агентство по продвижению Wildberries

## Реклама

[Реклама](https://shadyav.github.io/e-comet-landing-demo/docs/ad/campaigns/start/) - комплексное управление продвижением на Wildberries в автоматическом или полуавтоматическом режимах.

- Быстрый и надежный биддер с обновлением раз в 3 минуты
- Интеллектуальное управление ставкой с алгоритмом быстрой сходимости к целевой позиции
- Полная статистика рекламных кампаний за максимально доступный период времени, включая автоматический расчет всех маркетинговых метрик (CTR, CPC, CPO, ДРР и др.)
- Детальная статистика по ключевым фразам
- Массовое изменение настроек и создание рекламных кампаний
- Остановка РК при достижении заданных порогов (остатка, дневного расхода, наличия негативных отзывов и др.)

> **Совет. Безопасность.**
> Управление рекламными кампаниями осуществляется через API в полном соответствии с условиями оферты Wildberries.

## А/Б-тесты

[А/Б-тесты](https://shadyav.github.io/e-comet-landing-demo/docs/ab-tests/overview/) - автоматический подбор самой эффективной главной фотографии товара на основе общей статистики или статистики по общим кластерам.  

Мы тестируем до 10 фото одновременно, используя более точный метод ([основной метод](https://shadyav.github.io/e-comet-landing-demo/docs/ab-tests/stats/)) сравнения по общему семантическому ядру - набору кластеров, по которым были показы у всех тестируемых фото, что обеспечивает более точные результаты.

Также доступен ускоренный тест ([экспресс метод](https://shadyav.github.io/e-comet-landing-demo/docs/ab-tests/stats/)) на основе общей статистики артикула - первые результаты становятся видны уже через 1 час после запуска.

## Портфель

[Портфель](https://shadyav.github.io/e-comet-landing-demo/docs/portfolio/) - аналитика по артикулам, сгруппированная по вашему усмотрению: по брендам, юрлицам, типам товаров. Инструмент для мониторинга и сравнения показателей ваших товаров и товаров конкурентов.

Основные показатели за 30 дней с динамикой:

- Заказы
- Цена
- Выручка
- Видимость по категориям
- Видимость по ключевым фразам
- Количество рекламных кампаний
- ДРР

> **Важно. Конкуренты без цифр.**
> Данные по заказам, остаткам и выручке показываются только для своих товаров. Для товаров-конкурентов эти данные ВБ больше не раскрывает.

## Фразы

[Фразы](https://shadyav.github.io/e-comet-landing-demo/docs/phrases/) - миллион популярных запросов Wildberries (с частотностью), а также фразы из ваших рекламных кампаний для мониторинга позиций товаров в поисковой выдаче.

Также есть возможность добавления собственных ключевых фраз для отслеживания промопозиций или органических позиций. Глубина отслеживания - 100 первых страниц поисковой выдачи, т.е. 10 000 позиций.

## Лента

[Лента](https://shadyav.github.io/e-comet-landing-demo/docs/lenta/) - мониторинг заказов ваших товаров в режиме реального времени (обновление раз в 30 минут).

Удобная сортировка: по юрлицу, категории, бренду или артикулу. Также можно отследить возвращенные заказы.

Для каждого артикула отображается количество рекламных кампаний и удобный переход к ним.

## Другие функции

[Расширение](https://shadyav.github.io/e-comet-landing-demo/docs/tools/extension/) для браузера - позволяет прямо на страницах Wildberries видеть:

- Рекламные позиции
- Остатки по складам и размерам
- Информацию о поставщике и бренде, дате появления товара

> **Внимание. Точность остатков.**
> Wildberries ограничивает отображение остатков до 100 штук на размер / склад. Если фактическое количество превышает это значение, точный остаток определить не получится. Это ограничение, которое невозможно обойти.

[Функциональные](https://shadyav.github.io/e-comet-landing-demo/docs/tools/sheets/) таблицы - каждая таблица в сервисе поддерживает:

- Управление шириной, расположением и видимостью колонок
- Сортировку
- [Фильтрацию](https://shadyav.github.io/e-comet-landing-demo/docs/tools/filter/) по заданным условиям
- Экспорт в буфер обмена и в файлы CSV / Excel (.csv / .xlsx)
- Автоматический расчет среднего значения, количества и суммы выделенных ячеек
