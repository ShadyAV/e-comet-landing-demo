# Расширение для браузера e-Comet

Источник: https://shadyav.github.io/e-comet-landing-demo/docs/tools/extension/ · Обновлено: 20 ноября 2026

Расширение для браузера – это дополнительный плагин, который можно установить прямо в браузере, чтобы добавить в него определенные функции.

Расширение e-Comet полностью бесплатное, а скачать его можно по [ссылке](https://chromewebstore.google.com/detail/e-comet/apeallgchpgibifmbgefkhifidihmodh?from=site).

Оранжевая рамка выделяет рекламный товар. Цифры 1 и 2 вверху карточек на снимке — позиции этих товаров в выдаче Wildberries. Под карточкой видны артикул, остаток, бренд и поставщик. Нажмите на артикул, чтобы открыть товар в e-Comet, или на значок двух листов рядом с ним, чтобы скопировать номер.

![Два рекламных товара на первом и втором местах выдачи Wildberries. Возле артикулов видны значки ссылки и копирования.](https://shadyav.github.io/e-comet-landing-demo/docs/img/extension1.webp)

> **Внимание. Активация.**
> Для активации расширения необходима регистрация на сайте.

Наличие расширения необязательно для использования сервиса. Это просто дополнительный инструмент для вашего удобства, который позволяет выводить данные с сервиса прямо на страницы маркетплейса.

> **Внимание. Проверяйте в авторизованной выдаче.**
> Выдача на Wildberries для авторизованных и неавторизованных пользователей различается. Поэтому мы рекомендуем установить расширение, чтобы проверять позиции именно в авторизованной выдаче и получать максимально точные данные. Использование расширения помогает анализировать позиции корректно.

> **Совет. Расширение безопасно.**
> Расширение безопасно и не может привести к блокировке кабинета. Оно использует только публичную информацию с маркетплейса и не отправляет запросы через личный кабинет.

## Возможности
Расширение позволяет прямо на Wildberries видеть:

- рекламные позиции 
- графики за 30 дней по остаткам и цене
- остатки по складам и размерам
- информацию о поставщике и бренде, дате появления товара

> **Внимание. Точность остатков.**
> Wildberries ограничивает отображение остатков до 100 штук на размер / склад. Если фактическое количество превышает это значение, точный остаток определить не получится. Это ограничение, которое невозможно обойти.

## Установка

Расширение адаптировано для браузера Google Chrome, но также корректно работает в Яндекс Браузере и Microsoft Edge.

1. Откройте [e-Comet в Chrome Web Store](https://chromewebstore.google.com/detail/e-comet/apeallgchpgibifmbgefkhifidihmodh?from=site) и нажмите «Установить».

![Карточка расширения e-Comet в Chrome Web Store](https://shadyav.github.io/e-comet-landing-demo/docs/img/extension2.webp)

2. Откройте настройки расширения и убедитесь, что оно включено.
3. Проверьте разрешения в блоке «Доступ к сайтам».

![Переключатель расширения e-Comet и разрешения для сайтов в браузере](https://shadyav.github.io/e-comet-landing-demo/docs/img/extension3.webp)

4. Скопируйте ключ API расширения из [личного кабинета e-Comet](https://app.e-comet.io/account):

![Ключ расширения в карточке аккаунта](https://shadyav.github.io/e-comet-landing-demo/docs/img/account-user-card.webp)

5. В расширении e-Comet вставьте скопированный ключ в поле «Ключ расширения».
6. Нажмите «Подключить».

![Первое подключение расширения e-Comet](https://shadyav.github.io/e-comet-landing-demo/docs/img/extension5.webp)

Можете проверить работоспособность расширения, перейдя на клиентский портал Wildberries и введя любой поисковый запрос.

Вы увидите  в режиме реального времени и дополнительную информацию по каждому товару.
