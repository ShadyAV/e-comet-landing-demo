# Остались вопросы?

Источник: https://shadyav.github.io/e-comet-landing-demo/docs/support/ · Обновлено: 20 ноября 2026

Напишите нам в чат поддержки (оранжевый виджет в правом нижнем углу [в приложении](https://app.e-comet.io)) - мы работаем без выходных и праздников.

Также доступны видео-консультации:
- для всех клиентов, впервые оформивших подписку на платный тариф - бесплатный онбординг (первичное описание основного функционала на примере вашего подключенного кабинета)
- для тех, кому нужна дополнительная консультация по работе сервиса или повтор онбординга  - платная услуга

Напишите в поддержку, чтобы мы могли подобрать удобное для вас время :)
