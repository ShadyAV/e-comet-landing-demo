С чего начать

Подключить кабинет

Добавьте юрлицо и подключите к нему сервисный токен API Wildberries — без него сервис не увидит кабинет.

Запустить рекламу

Подключите кампании из кабинета Wildberries или создайте новые, а потом отдайте их под управление биддера.

Проверить фото

Запустите А/Б-тест главного фото за семь шагов и сравните конверсию в клик и в корзину у каждого снимка.
