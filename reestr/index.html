Описание программного обеспечения

Программа для ЭВМ «e-Comet» — это платформа для аналитики и автоматизации продвижения на маркетплейсах. Программное обеспечение представляет собой набор инструментов для анализа и повышения эффективности рекламных кампаний.

Единый реестр российского ПО

Программа для ЭВМ «e-Comet» включена в Единый реестр российских программ для электронных вычислительных машин и баз данных. Реестровая запись №33137 от 17.04.2026, правообладатель — ООО «Е-КОМЕТ».

Основной класс: 12.14 Программное обеспечение для решения отраслевых задач в области рекламы.

Функциональные характеристики

Программа для ЭВМ «e-Comet» обеспечивает выполнение следующих функциональных возможностей:

  • Автоматизированное и полуавтоматизированное управление внутренней рекламой на Wildberries;
  • Управление ставками рекламных кампаний с регулярным обновлением и удержанием целевых позиций;
  • Массовое создание, изменение и контроль параметров рекламных кампаний;
  • Автоматическая остановка рекламных кампаний по заданным условиям (остатки, лимиты расходов, негативные отзывы и иные пороги);
  • Сбор, хранение и анализ статистики рекламных кампаний с автоматическим расчетом ключевых метрик (CTR, CPC, CPO, ДРР и др.);
  • Детальная аналитика по ключевым фразам и мониторинг позиций товаров в поисковой выдаче;
  • Работа с базой популярных поисковых запросов и добавление пользовательских фраз для отслеживания;
  • Проведение A/B-тестов главных фотографий товара (в том числе одновременное тестирование нескольких вариантов);
  • Портфельная аналитика по артикулам с группировкой по брендам, юрлицам и типам товаров, а также сравнительный мониторинг показателей;
  • Табличные инструменты анализа данных: фильтрация, сортировка, настройка колонок, экспорт в CSV/XLSX, расчет агрегатов по выделенным данным;
  • Поддержка браузерного расширения для отображения рекламных позиций и товарной аналитики непосредственно на страницах Wildberries;
  • Безопасная работа через официальный API Wildberries.
