# e-Comet — демо лендинга и базы знаний

[Лендинг](https://shadyav.github.io/e-comet-landing-demo/) · [База знаний](https://shadyav.github.io/e-comet-landing-demo/docs/)

Статический предпросмотр. В базе доступны поиск, переключение темы, иллюстрации и записи экрана. Формы и чат не отправляют данные. В форме оценки статьи можно выбрать ответ и ввести комментарий. Тарифы показаны по снимку публичных цен на дату сборки.
